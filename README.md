# Remibuds

Official landing page for **Remibuds** — a free, private reminder app for medicines, creams and daily routines (Android).

- **Website:** served from this repository via GitHub Pages (`index.html`)
- **App:** `remibuds-2.0.4.apk` (v2.0.4, Android, free, no ads, no account, on-device only)

Made with ♥ by Vijay Mamta Sahani — [@momentswithvms](https://www.instagram.com/momentswithvms/) on Instagram.

- **Source code:** `source/` — the full Remibuds 2.0.4 source (Android app + web UI + tests). The app signing key is kept offline and is not in this repository.
